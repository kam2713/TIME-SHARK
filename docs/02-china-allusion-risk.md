# 02. 실존 국가(중국) 암시 리스크 검토

> 작성일: 2026-10-20 · 상태: **검토 중** (방향 미결정 — 하단 "결정 필요 사항" 참고)

## 1. 문제 제기

가상 국가라도 중국을 너무 직접적으로 암시하면 출시 후 문제가 생길 수 있다는 우려.

**솔직한 자기 점검:** [v0.1 컨셉안](./01-concept-v0.1.md)은 "가상 국가"라고 했지만, 실제로는 중국 코드가 매우 강하다.
- "인민공화국", 천명(天命)·천안(天眼) 같은 한자 명칭, 저우밍·샤오위라는 중국식 이름, 얼후·고쟁 사운드가 겹쳐 있다.
- 이 정도면 플레이어 대부분이 "중국 이야기"로 읽는다.
- 특히 **天眼**은 중국의 실제 대형 전파망원경(FAST)의 별칭이다. 중국 감시망 이름 **天网(톈왕)**과도 한 글자 차이다.

## 2. 실제로 생길 수 있는 문제

| 리스크 | 내용 | 심각도 |
|---|---|---|
| **리뷰 폭탄** | 중국어권 유저의 집단 부정 리뷰. 스팀은 2019년부터 "주제와 무관한 리뷰 활동"을 감지해 점수 계산에서 제외하는 장치가 있지만, 리뷰 텍스트 자체는 남고 커뮤니티 분위기가 오염된다 | 중 |
| **파트너·자본 이탈** | 퍼블리셔, 투자사, 외주 스튜디오, 미들웨어사가 중국 사업과 얽혀 있으면 계약이 끊길 수 있다 | **상** |
| **시장 손실** | 스팀 언어 설문에서 간체 중국어 사용자는 최상위권 비중이다. 중국어권 판매를 사실상 포기하게 될 수 있다 | 중~상 |
| **향후 사업 제약** | 같은 회사의 다음 작품이 중국 판호를 받거나 중국 퍼블리셔와 협업하기 어려워질 수 있다 | 중 |
| **스토어 노출** | 스팀 글로벌 자체는 정치적 게임을 허용한다. 다만 지역별 판매 제한 같은 변수는 있을 수 있다 | 하~중 |

### 참고 사례: 《환원(還願, Devotion)》 (2019, 대만 Red Candle Games)
- 게임 속 부적 소품에 시진핑 주석을 곰돌이 푸에 빗댄 밈이 숨겨져 있었다.
- 그 결과 중국어권 리뷰 폭탄이 일어났고, 중국 측 퍼블리싱 파트너가 계약을 해지했다.
- 개발사는 결국 스팀에서 게임을 내렸다(이후 자체 스토어로 판매).
- **교훈:** 문제가 된 건 "권위주의 비판"이라는 주제가 아니었다. **특정 실존 지도자를 조롱하는 구체적 요소** 하나였다.

## 3. 핵심 원칙

> **"떠올리는 것"은 막을 수 없고 막을 필요도 없다. "특정·조롱의 근거"를 남기지 않는 것이 목표다.**

기술 권위주의를 다루는 이상 일부 플레이어는 어떤 형태로든 중국을 떠올린다. 그건 작품이 가진 보편성의 일부다. 리스크를 만드는 건 다음 두 가지다.
1. 특정 국가로 **확정**할 수 있는 고유한 기호
2. 실존 인물이나 사건을 **조롱·희화화**하는 요소

## 4. 절대 넣지 않을 것 (레드라인)

- [ ] 실존 지도자를 닮은 캐릭터, 외모, 별명, 밈 (곰돌이 푸 등 포함. 숨겨진 이스터에그도 금지)
- [ ] 실제 역사적 사건의 재현이나 암시 (천안문 1989, 탱크맨, 홍콩 우산, 신장 수용소 등)
- [ ] 실제 국기, 국장, 별 문양의 변형
- [ ] 실제 지명, 실제 정당명, 실제 구호의 패러디 ("중국몽" 등)
- [ ] 실제 앱이나 기업의 UI 패러디 (위챗 등). **배달원 유니폼 색도 주의:** 메이퇀은 노랑, 어러머는 파랑이다
- [ ] 특정 민족이나 국민 전체를 악으로 묘사하는 표현

> 📌 아트·사운드 외주를 맡길 때 이 레드라인을 **계약서에 명시**한다. 《환원》 사례처럼 소품 하나가 문제가 될 수 있다.

## 5. 중국 코드 점검표 (v0.1 기준)

| 요소 | 중국 연상도 | 조치 방향 |
|---|---|---|
| "인민공화국" 국호 | 매우 높음 | **교체** |
| 천명·천안 등 한자 명칭 | 매우 높음 | **교체** |
| 저우밍·샤오위 등 중국식 인명 | 높음 | **교체** |
| 얼후·고쟁 사운드 | 중간 | 특정 문화권 악기 대신 변조 현악기, 합창, 신스 등으로 |
| "사회신용점수"라는 용어 | 중간 (개념 자체는 *블랙 미러* 「추락」 등으로 보편화됨) | 개념은 유지하고 명칭만 교체 (예: 시민 지수, 신뢰도) |
| 연좌제 | 중간 (조선, 북한, 동독 등 여러 역사에 존재) | 유지 가능 |
| 맹점(盲點) 같은 한자 표기 | 낮음 | 한글이나 영문 표기로 |
| 배달 라이더 주인공 | 낮음 (전 세계 공통) | 유지 |
| 감시 AI, 예측 치안 | 낮음 (미국 예측치안, 빅테크 알고리즘 등 보편적) | 유지 (핵심) |

## 6. 대안 방향 3가지

### A안. 동아시아 분위기 유지 + 직접 기호 제거
- 동아시아 거대도시의 질감(밀도, 네온, 고층 아파트)은 유지한다.
- 국호, 한자, 인명, 상징은 모두 가상 조어로 바꾼다.
- 장점: 원래 구상한 분위기를 가장 많이 살린다.
- 단점: 그래도 "중국 같다"는 인상은 상당히 남는다.

### B안. 국가 + 플랫폼 기업의 융합 체제 ★ 권장
- 정부와 거대 플랫폼 기업의 경계가 사라진 체제로 설정한다. 시민 점수 알고리즘은 원래 배달·쇼핑 앱의 평점 시스템이었고, 그게 국가 운영 체계가 됐다.
- 비판의 대상이 특정 국가가 아니라 **"기술과 권력이 결합하는 방식 그 자체"**가 된다.
- 장점:
  - 특정 국가로 읽힐 근거가 크게 줄어든다.
  - 서구·한국·일본 플레이어에게 "우리 이야기일 수도 있다"는 공포를 준다. 감시 자본주의, 긱 이코노미와 맞닿아 있다.
  - 배달 라이더 주인공 설정과 가장 자연스럽게 이어진다. 배달 앱 평점이 시민 점수로 진화한 구조.
- 단점: "권위주의 국가의 억압"이라는 직접적 긴장감이 다소 약해질 수 있다. 연출로 보완해야 한다.

### C안. 다국적 혼합 디스토피아
- 동유럽 브루탈리즘 건축, 동아시아 메가시티, 실리콘밸리 기업 문화, 냉전기 밀고 문화(동독 슈타지 등)를 의도적으로 섞는다.
- 장점: 어느 한 나라로도 특정되지 않는다.
- 단점: 정체성이 흐려져 "어디서 본 디스토피아"가 될 위험이 있다.

> **현재 권장: B안을 뼈대로 하고 C안의 혼합 요소를 일부 차용.** 도시 질감은 다국적으로 섞되, 체제의 본질은 "앱이 국가가 된 나라"로 잡는다.

## 7. 명칭 교체 아이디어 (후보, 미확정)

| 항목 | v0.1 | 후보 |
|---|---|---|
| 감시 AI | 천안(天眼) | 「등대(LIGHTHOUSE)」, 「자오선(MERIDIAN)」, 「목자(SHEPHERD)」 |
| 국가 | 천명 인민공화국 | 가상 조어의 연합 또는 도시국가 (예: "○○ 연합", "○○ 시티") — 추후 결정 |
| 점수 | 사회신용점수 | 시민 지수(Civic Index), 신뢰도(Trust Rating), 별점 |
| 주인공 이름 | 저우밍 | 공식 호칭은 **라이더 ID "R-0612"**, 실명은 가족만 부른다 (아래 참고) |
| 저항 조직 | 맹점(盲點) | 「사각지대」, 「블라인드 스팟」, 「오프라인」 |

**주인공 호칭 아이디어:** 체제는 주인공을 이름 대신 라이더 ID로 부른다. 실명은 딸과 어머니만 부른다. 국적 문제를 피하는 동시에, "이름을 되찾는 것"을 서사의 상징으로 쓸 수 있다.

## 8. 사업적으로 미리 확인할 것

- [ ] 퍼블리셔나 투자사의 중국 사업 연관성 (지분, 주요 매출처)
- [ ] 외주 스튜디오(아트, QA, 현지화)의 소재지와 계약 조건
- [ ] 간체 중국어 현지화 여부. 하지 않으면 중국어권 노출은 줄지만 리뷰 폭탄 리스크도 줄어든다. 번체(대만·홍콩) 현지화는 별도로 판단한다
- [ ] 엔진, 미들웨어 라이선스의 지역 제약 여부
- [ ] 스토어 페이지와 트레일러에서 "중국"을 연상시키는 마케팅 문구 배제

> ⚠️ 위 내용은 기획 단계의 리스크 검토다. 실제 계약과 퍼블리싱 결정 전에는 퍼블리셔나 법률 전문가와 확인한다.

## 9. 결정 필요 사항

1. 세계관 방향: A / **B(권장)** / C 중 선택
2. 감시 AI, 국가, 점수 시스템의 최종 명칭
3. 간체 중국어 현지화 여부
4. 동아시아적 분위기를 어느 정도 남길지 (0~100% 스펙트럼)
